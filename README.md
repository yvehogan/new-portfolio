# Evelyn Ita Hogan · Portfolio

Personal portfolio built with Next.js (App Router), TypeScript and Tailwind CSS v4.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit the content

All text lives in `src/lib/data.ts`: profile and links, hero stats, featured projects, experience, skills, education and mentoring.

## Structure

- `src/app/` – layout, fonts, metadata and the theme in `globals.css`
- `src/components/` – page sections (`Hero`, `Projects`, `Experience`, `About`, `Contact`) and the animation helpers (`Reveal`, `Tilt`, `Typewriter`, `Counter`)
- `src/lib/data.ts` – content
